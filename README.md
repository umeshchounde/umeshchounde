# Umesh Chounde

**Privacy engineer** building open-source tooling and research that turn US state privacy laws into enforceable, automated data controls.

## Focus

US organizations now face a growing patchwork of state privacy laws: CCPA/CPRA, Virginia VCDPA, the Washington My Health My Data Act, Nevada SB 370. Most compliance work is still manual and hard to audit. I work on making it automated, testable and open.

**Current endeavor (independent work):**
- An open-source classifier for consumer health data, built around a *content-based vs. use-based* classification model, so organizations can tell when data counts as consumer health data under different state laws.
- A systems paper describing the model, in preparation for PoPETs 2027.

## Background

- Senior Software Engineer, 9 years in industry; tech lead for implementing CCPA, VCDPA and MHMDA controls across an enterprise-scale data lake.
- Designed a multi-agent PII classification system (deterministic core with LLM-judge evaluation) spanning roughly 30 regulatory regimes.
- MS in Computer Science; former graduate teaching assistant at UNC Charlotte.
